# Ammar Mahmoud - Portfolio

A modern and responsive personal portfolio website built with React and Vite.

This portfolio showcases my skills, projects, experience, and professional background through a clean and interactive web experience.

## Features

- Responsive design
- Modern and clean user interface
- Personal introduction and profile section
- Skills and technologies showcase
- Projects showcase
- Professional experience section
- Contact section
- Responsive navigation
- Reusable React components
- Lucide React icons
- Fast development with Vite
- ESLint integration for code quality

## Tech Stack

| Technology | Purpose |
|---|---|
| React | Frontend UI library |
| Vite | Development server and build tool |
| JavaScript | Programming language |
| HTML5 | Page structure |
| CSS3 | Styling and responsive design |
| Lucide React | UI icons |
| ESLint | Code quality and linting |
